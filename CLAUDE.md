# vendaval-web (PUBLIC)

Website vendaval.cat and all promoter material of Cia. VENDAVAL (show dossiers, riders, flyer). This repo is public: never add fees, budgets, NIF, personal data or application answers. Those go in the private repo `ciaVENDAVAL/vendaval-docs` (see its `INDEX.md` for where every document lives).

- Facts: Project doc `master/VENDAVAL master fact sheet.md` (claude.ai Project "VENDAVAL"). Update it and every language when a fact changes.
- How to update: `UPDATING.md`. Check before pushing: `python3 tools/check.py`.
- Build: `python3 build.py` (site) · `python3 dossiers/build_dossiers.py <folder> [langs]` (imaginary-friend, el-joc-etern, ani-arqui, easy-brass, easy-friend, easy-stilts) · `python3 dossiers/stilts-workshops/build.py` · `python3 dossiers/brass/build.py` · `python3 dossiers/concert/build.py` (Concert in the audience) · `python3 tools/flyer.py ca es en` · agenda from the public calendar: `python3 tools/agenda_sync.py` · logo vector + outline files for Downloads → Graphics (only when the logo changes): `python3 tools/logo_vector.py`.
- **Always `git pull --rebase` first**: the admin (`/admin/`), the on-page editor (`#edit`) and the build bots commit to `main`. A rebase conflict only in `docs/` → take theirs, rebuild (`python3 build.py`), continue.
- Push: build, commit (author tyle fernández <VENDAVAL@anartist.org>), `git push origin HEAD:main`. GitHub Pages serves `docs/`. Pushes start `.github/workflows/build.yml` (translate CA↔ES↔EN → build → check → commit docs/) and, for `dossiers/**`, `dossiers.yml` (rebuild changed PDFs). Put `[no-translate]` / `[no-pdf]` in the commit message when you already did that work yourself.
- Admin (Sveltia CMS) at `static/admin/` → www.VENDAVAL.cat/admin/: forms generated by `python3 tools/make_config.py` (run it after adding/removing keys in content/ or dossier texts). On-page editor: `static/assets/edit.js` + loader at the end of `src/page.html`.
- Translations: `tools/translate.py` (Softcatalà models, CA/ES/EN only). DE/FR/IT/JA changes go to `content/i18n/_needs-translation.json` (CHECK-REPORT.md §8): translate them (German wording rules in the fact sheet §6c) and remove the entry.
- PDFs replaced by hand: `downloads.<key>.manual` in content/data.json (CHECK-REPORT.md §7). Build scripts skip them unless `--force`. When the source matches again, remove the flag and rebuild.
- Dossier JSON tables are stored as `{"a": …, "b": …}` rows (for the admin forms); `dossiers/texts.py` turns them back into lists for the templates. Per-language data values in content/data.json use the key `"all"` for "every language".
- Easy read: web texts in `content/easy/<lang>.json` (shown with the accessibility option), easy-read dossiers in `dossiers/easy-*/`. Not validated by easy-read users yet: no official Lectura Fàcil / Leichte Sprache logo.
- House style: VENDAVAL always in capitals, also in addresses as displayed (www.VENDAVAL.cat, VENDAVAL@anartist.org; URL paths stay lowercase); no salsa in the genre lists (funk, Balkan, swing, cumbia); tyle fernández lowercase; never "tothom"; don't call performers clowns in show texts; never crop photos; prices never public; place names in each language's form; 7 languages kept consistent (CA ES EN DE FR IT JA; Portuguese removed 6 Nov 2026).
